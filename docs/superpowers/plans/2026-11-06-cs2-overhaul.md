# CS2 玩法重整实施计划

> 使用 superpowers:executing-plans 在当前会话逐项执行。

**Goal:** 统一购买、回合、战斗显示、旁观接管与可靠Bot，修复换边出生。
**Architecture:** UE5.4原生插件管理规则与适配，保留Kit实际射击/动画；规则和经济用不依赖UE的C++核心验证。
**Tech Stack:** UE5.4.4、C++、Blueprint、Python编辑器脚本。
**Spec:** docs/superpowers/specs/2026-11-06-cs2-overhaul-design.md

## 约束与审阅重点

原始归档不改；canonical插件和工作工程同步；不移动已安装BuildTools目录；无Git仓库，用Backups和文件哈希。重置途中角色不全、蹲伏/接管后的姿态、携包死亡与接管、断网模型超时和跨回合资产泄漏必须有对应验证。

### 1. 出生与AI稳定性

- [ ] 读取玩家实际日志与蓝图默认姿态，复现部分阵容反复放置和换边脚底问题。
- [ ] 写出生脚底/镜头/胶囊与每个Bot导航诊断；旧逻辑下记录失败。
- [ ] CS6TacticalMatch::Enroll改为齐备后一次登记，安全地面放置与姿态恢复；新增独立CS6SpawnPlacement工具。
- [ ] AI目标请求缓存、失败回退、移动进度与卡住脱困；验证每个承担移动目标的Bot有进展或明确的守点/战斗状态。

### 2. CS2回合与经济核心

- [ ] 新测试先使旧7/8规则失败；RoundRules改为MR12、13胜、12:12平局及可配置加时。
- [ ] 新EconomyRules及测试：800/16000、合法购买退款、奖励、换边、保枪；失败→实现→通过。
- [ ] 接入UE玩家与Bot库存，真实资产商品、B购买菜单/购买区时间限制；渲染验收。

### 3. 枪包与无关机制清理

- [ ] 新枪包骨架/动画/蓝图清单；接入兼容枪械并记录适配偏差。
- [ ] 关闭冲刺/侧身/夜视/职业/配件/TDM入口，保留CS2需要的操作；测试原武器动画不受损。

### 4. HUD和旁观接管

- [ ] 新CS6CombatOverlay和购买界面，绑定真实战斗状态，Tab显示统一计分。
- [ ] 本队视角切换、E接管Bot；测试人数/队伍/状态保持、不能控制敌人或死亡Bot。

### 5. 回归与独立包

- [ ] Editor/Game编译，渲染下购买→战斗→死亡→旁观接管→换边，整场及每个Bot检查。
- [ ] 只读代码审阅、修复实际问题；更新独立包、控制说明和当前状态。
- [ ] 服务名称/接口补充后接入可选模型战术建议，验证超时回退；在此之前本地AI照常运行。
